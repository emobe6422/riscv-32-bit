# Single-Cycle-RV32I-All-Instructions

RV32I is a popular open-source CPU ISA/microarchitecture that I followed to create the RTL present.

Designed for IRL synthesis on the Basys 3 Artix 7, so certain design choices (no for/while loops, no initial begin (with exception), etc, etc.) were made. Once I finished this, the CPU served as the base for my Space Invaders replica in the Stellar Phenomena github repo.
